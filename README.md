# 💻 Example Question

```python
# Armstrong Number Check

def armstrong_number(n: str):
    length = len(n)
    total = 0

    for digit in n:
        total += int(digit) ** length

    if total == int(n):
        return f"{n} is an Armstrong Number"

    return f"{n} is not an Armstrong Number"

print(armstrong_number("1634"))
```
